# Source and experiment history

The source workspace had no root Git repository. This project preserves the actual upstream ThinkingCap-Test history, then adds contemporary import/refactor commits. Original experiment dates come from immutable result records and source snapshots, not invented commits.

provenance/import.json records hashes of imported research files. The self-replay/on-policy-distillation/adaptive-replay/teacher-replay source manifests identify actual archived workers; source overlays recover their scientific implementation. Portable runtime construction separately records current file hashes and any source-lock changes.

provenance/evidence.json is an allowlisted export ledger for published result files and local release assets. Historical complete checkpoint manifests include optimizer/RNG files that are not shipped in the inference releases: the release manifest distinguishes included files from historical-only references. Deleted historical intermediate states are not reconstructed or represented as available.

Original lab artifacts, nested repositories and running services are unchanged by this public export. The repository excludes obsolete per-seed convenience launchers from its ordinary runtime while retaining their original import ancestry and any versions required by a historical overlay.
